# Trufi TileServer GL

A self-hosted vector tile server using [TileServer GL](https://github.com/maptiler/tileserver-gl) for serving OpenMapTiles-compatible vector tiles.

## Features

- Serves vector tiles from `.mbtiles` files
- Multiple map styles included (OSM Bright, MapTiler Basic, OSM Liberty)
- Docker-based deployment
- Compatible with Mapbox GL JS, MapLibre GL JS, and other vector tile clients

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)
- An `.mbtiles` file with vector tiles (e.g., from [OpenMapTiles](https://openmaptiles.org/))

## Quick Start

```bash
# Clone the repository
git clone <repository-url>
cd trufi-server-tileserver-gl

# Initialize with bbox and mbtiles file
./init.sh BBOX=29.979526,-2.079821,30.27987,-1.779581 /path/to/kigali.mbtiles

# Start the server
docker compose up -d
```

Access the server at http://localhost:5656

## Available Endpoints

Once running, TileServer GL provides:

| Endpoint | Description |
|----------|-------------|
| `/` | Web interface with map preview |
| `/styles/` | List of available styles |
| `/styles/{style}/style.json` | Mapbox GL style JSON |
| `/styles/{style}/{z}/{x}/{y}.png` | Raster tiles |
| `/data/` | List of available data sources |
| `/data/{source}/{z}/{x}/{y}.pbf` | Vector tiles (Protocol Buffers) |
| `/data/{source}.json` | TileJSON metadata |
| `/fonts/` | Available fonts |
| `/health` | Health check endpoint |

### Available Styles

- `osm-bright` - OSM Bright style
- `maptiler-basic` - MapTiler Basic style
- `osm-liberty` - OSM Liberty style

## Using with Mapbox GL JS / MapLibre GL JS

```javascript
const map = new maplibregl.Map({
  container: 'map',
  style: 'http://localhost:5656/styles/osm-bright/style.json',
  center: [30.06, -1.94], // Kigali coordinates
  zoom: 12
});
```

## Network Integration

This service connects to the `trufi-server` Docker network, allowing it to be accessed by other Trufi services.

To use with an external Nginx proxy, see `nginx.conf` for the reverse proxy configuration.

## Generating MBTiles

You can generate your own `.mbtiles` files using [OpenMapTiles](https://github.com/openmaptiles/openmaptiles):

```bash
# Clone OpenMapTiles
git clone https://github.com/openmaptiles/openmaptiles.git
cd openmaptiles

# Generate tiles for your area
./quickstart.sh <area-name>

# Copy the generated mbtiles
cp data/tiles.mbtiles /path/to/trufi-server-tileserver-gl/data/
```

## Troubleshooting

### Container won't start
Check if the `.mbtiles` file exists in the `data/` directory:
```bash
ls -la data/*.mbtiles
```

### Styles not loading
Verify the config was generated correctly:
```bash
docker-compose exec trufi-tileserver-gl cat /data/config.json
```

### Check logs
```bash
docker-compose logs -f trufi-tileserver-gl
```
